Q1: Creative Phase – Defining an Analytics Idea
Project Overview
This project proposes a Pacing Consistency Insight Tool designed for collegiate Track & Field programs. The idea focuses on creating a simple, coach‑friendly metric that summarizes how consistently an athlete maintains pace across intervals, reps, or race segments. Rather than producing complex models, the tool emphasizes clarity, usability, and alignment with how coaches already evaluate performance.

The core concept:
A single pacing‑consistency score that highlights variation in splits and flags reps where athletes deviate from target pace.

This tool would serve as a lightweight decision‑support resource that helps coaches quickly identify whether an athlete is progressing, fatiguing, or ready for load adjustments.

Decision-Making Problem
Coaches frequently make training decisions based on perceived effort, athlete feedback, and stopwatch timing. However, pacing inconsistencies—especially small deviations—are often overlooked or difficult to track across multiple reps.

This analytics idea supports the following decision-making needs:

Determining whether an athlete is ready for increased training load

Identifying fatigue patterns during interval sessions

Adjusting pacing targets for upcoming workouts

Evaluating race-readiness based on consistency trends

The problem: Coaches need a simple, actionable way to quantify pacing consistency without sifting through raw split data. Proposed Analytics Approach
No implementation is required, but the conceptual approach includes:

Data Needed:

Split times for intervals or race segments

Target pace for the session

Athlete identifiers and session metadata

Analysis Concept:

Calculate variation between actual splits and target pace

Summarize variation into a single consistency score

Flag reps with unusually high deviation

Visualize trends across sessions (optional future enhancement) Use by Decision Makers
A coach or performance staff member would interact with the tool in the following ways:

View a simple pacing consistency score after each workout

Quickly identify reps where the athlete deviated from target pace

Use the score to guide conversations with athletes about pacing discipline

Incorporate consistency trends into weekly training adjustments

Reference the tool during planning meetings to justify load changes

The goal is not to overwhelm coaches with data, but to enhance existing decision-making processes with a clear, digestible metric. Connection to Chapter 7

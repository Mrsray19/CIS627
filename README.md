Q1: Creative Phase – Defining an Analytics Idea
Project Overview
This project proposes a Pacing Consistency Insight Tool designed for collegiate Track & Field programs. The idea focuses on creating a simple, coach‑friendly metric that summarizes how consistently an athlete maintains pace across intervals, reps, or race segments. Rather than producing complex models, the tool emphasizes clarity, usability, and alignment with how coaches already evaluate performance.

The core concept:
A single pacing‑consistency score that highlights variation in splits and flags reps where athletes deviate from target pace.

This tool would serve as a lightweight decision‑support resource that helps coaches quickly identify whether an athlete is progressing, fatiguing, or ready for load adjustments.

Decision-Making Problem
Coaches frequently make training decisions based on perceived effort, athlete feedback, and stopwatch timing. However, pacing inconsistencies—especially small deviations—are often overlooked or difficult to track across multiple reps.

This analytics idea supports the following decision-making needs:

Determining whether an athlete is ready for increased training load

Identifying fatigue patterns during interval sessions

Adjusting pacing targets for upcoming workouts

Evaluating race-readiness based on consistency trends

The problem: Coaches need a simple, actionable way to quantify pacing consistency without sifting through raw split data. Proposed Analytics Approach
No implementation is required, but the conceptual approach includes:

Data Needed:

Split times for intervals or race segments

Target pace for the session

Athlete identifiers and session metadata

Analysis Concept:

Calculate variation between actual splits and target pace

Summarize variation into a single consistency score

Flag reps with unusually high deviation

Visualize trends across sessions (optional future enhancement) Use by Decision Makers
A coach or performance staff member would interact with the tool in the following ways:

View a simple pacing consistency score after each workout

Quickly identify reps where the athlete deviated from target pace

Use the score to guide conversations with athletes about pacing discipline

Incorporate consistency trends into weekly training adjustments

Reference the tool during planning meetings to justify load changes

The goal is not to overwhelm coaches with data, but to enhance existing decision-making processes with a clear, digestible metric. Connection to Chapter 7
This idea is currently in the Creative Phase of innovation.

Why:

The concept is defined, but no prototype exists yet.

The idea is still being shaped and aligned with organizational needs.

No iteration, testing, or stakeholder engagement has occurred.

The focus is on articulating the problem and proposing a solution, which is the hallmark of the creative phase.

Q3: Prototype Evaluation
Should the Prototype Enhancement Be Integrated?
The prototype enhancement adding a fatigue trend indicator alongside the pacing‑consistency score shows meaningful potential, but it is not yet ready for full integration into the main project. While the concept strengthens the decision‑support value of the tool, it requires additional feedback from coaches and performance staff to ensure it aligns with real training workflows.

At this stage, the enhancement should remain in the prototype branch until decision makers confirm that the added complexity improves clarity rather than creating confusion.

Feedback Needed from Decision Makers
Before integrating the enhancement into the main project, the following feedback would be essential:

1. Coach Usability Feedback
Do coaches understand the fatigue trend indicator quickly?

Does the metric help them make training decisions faster?

Does it fit naturally into how they already evaluate pacing and fatigue?

2. Practical Workflow Fit
Would coaches actually use this metric during weekly planning?

Does it complement existing tools or create redundancy?

Is the metric simple enough to interpret during fast-paced training sessions?

3. Decision-Making Impact
Does the fatigue indicator meaningfully change how coaches adjust training loads?

Does it help identify fatigue earlier or more accurately than current methods?

Does it improve athlete communication and feedback sessions?

4. Data Requirements
Do coaches have consistent access to the split data needed to calculate fatigue trends?

Is the metric feasible to maintain across different training environments?

Evaluation Summary
The prototype enhancement shows strong potential but requires stakeholder engagement before merging into the main branch. The decision to integrate should be based on whether coaches find the metric:

Clear

Actionable

Easy to interpret

Useful for real training decisions

Until that feedback is gathered, the enhancement should remain in the prototype branch for further refinement.

Q4: Integration Decision
After evaluating the prototype enhancement, the decision is not to merge the prototype branch into the main project at this time. While the fatigue trend indicator shows strong potential, it requires additional feedback from coaches and performance staff to confirm that the metric is clear, actionable, and aligned with real training workflows.

Because further refinement and engagement with decision makers is needed, the prototype branch will remain separate until the enhancement is fully validated.
